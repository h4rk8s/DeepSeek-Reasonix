结构判断

字段分层，不是样式分层
环境层模型、CWD、Git、会话累计 tokens / cost / quota。低频但定位重要。 行为层YOLO / approval、plan、effort、当前 running / thinking / approval。高频状态，适合第一行。 资源层cache hit、avg、ctx、compact headroom、turn tokens / cost。最能解释 DeepSeek / Reasonix 体验差异，应优先可见。

三个基准方案

同一字段集，不同密度策略

Reasonix 2 行

第一行行为层，第二行资源层 + 环境尾部。适合半屏，保持 hit / ctx 不丢。

Claude 3 行

上：环境；中：行为；下：工具 / 资源。信息全，但更占垂直空间。

Codex 1 行

左到右严格优先级，极省空间；字段冲突时只能牺牲尾部信息。
